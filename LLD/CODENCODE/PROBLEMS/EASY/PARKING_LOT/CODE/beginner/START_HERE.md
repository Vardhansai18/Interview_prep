## 🎤 Elevator Pitch (Use This in Interviews!)

> "I designed a parking lot management system that demonstrates all SOLID principles. The architecture has three layers: models for domain objects like Vehicle and ParkingSpot, strategies for flexible pricing using the Strategy Pattern, and a service layer that orchestrates everything. The system supports multiple floors, different vehicle types, and handles edge cases like full parking lots. I used dependency injection for loose coupling and proper inheritance for extensibility. I can easily add new vehicle types or pricing strategies without modifying existing code, which follows the Open/Closed Principle."
